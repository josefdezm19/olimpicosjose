# Weightlifting 101 · Semanas 5–12

Webapp del programa *Weightlifting 101 – The Beginner's Cycle* (semanas 5 a 12).

- Navegación por semanas y días, con calendario semanal sugerido.
- Cálculo de kilos a partir del peso corporal y los 1RM de sentadilla.
- Seguimiento de series y progreso (guardado en el navegador).
- Temporizador de descansos e intervalos.
- Minirreproductor con los vídeos demostrativos.

Es un único archivo `index.html`, sin dependencias. Publicado con GitHub Pages.
